# E-Commerce CRUD (Local Storage)

A small e-commerce style web app built with plain HTML, CSS and JavaScript. Add products with a name, price, description and image URL, update or delete them, and everything is saved in the browser's localStorage — no backend needed.

## Features

- Add, update and delete products (CRUD)
- Product cards with image, name, description and price (₹)
- Data persists in localStorage
- Mobile responsive layout

## Tech

HTML · CSS · JavaScript (localStorage)

## Run it

Open `index.html` in any browser, or use a static server:

```bash
npx serve .
```
